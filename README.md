# Bank Customer Analysis

## Aim
To analyze customer age, account balance, and loan information using R programming.

## Description
This project uses sample banking customer data to calculate average balance, total loan amount, number of customers with loans, and the customer with the highest balance.

## Technologies Used
- R Programming
- Data Frames
- Basic Data Analysis

## Features
- Displays customer information
- Calculates average balance
- Calculates total loan amount
- Counts customers with loans
- Finds the highest-balance customer

## How to Run
1. Open `07_Bank_Customer_Analysis.R`.
2. Run the program in RStudio or VS Code.
3. View the results in the R console.

## Result
The program successfully analyzes the sample banking customer data.
